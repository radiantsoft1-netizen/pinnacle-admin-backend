IMPORTANT SECURITY NOTES:
═════════════════════════════════════════════════════════════════════

1. SAVE THESE CREDENTIALS SECURELY
   - Store in a password manager (1Password, LastPass, Bitwarden)
   - Do NOT commit to Git repository
   - Do NOT share via email or messaging apps

2. CHANGE PASSWORDS AFTER FIRST LOGIN
   - Log in to the admin panel
   - Go to Settings → Change Password
   - Create a strong, unique password
   - Update this file with new passwords

3. NEVER SHARE CREDENTIALS
   - Only provide to authorized staff members
   - Use separate accounts for different roles
   - Remove access when someone leaves

4. USE HTTPS IN PRODUCTION
   - Always access admin panel via HTTPS
   - Never use HTTP for admin login
   - Enable SSL/TLS certificate

5. BACKUP RECOVERY CREDENTIALS
   - Keep a copy of these credentials in a secure location
   - Use a safe deposit box or encrypted storage
   - In case account is locked or password is forgotten

RECOVERY PROCEDURES:
═════════════════════════════════════════════════════════════════════

If password is forgotten:
1. Contact the system administrator
2. Admin can reset password via database
3. Temporary password will be provided
4. Change password on next login

If account is locked:
1. Check database for login attempts
2. Reset login_attempts counter
3. Account will be unlocked
